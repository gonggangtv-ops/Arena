# ปราสาทหิมะ (snow-castle) — สเปกสำหรับสร้างใน Blender

เจ้าของสั่ง 2026-11-22: ปราสาทหิมะน้ำแข็งของราชินีหิมะ ให้ Codex สร้างใน Blender แล้วใส่เข้า Arena Royale (`index.html`)

ตอนนี้ในเกมมี "ปราสาทชั่วคราว" (กล่อง/ทรงกระบอก/กรวยน้ำแข็ง วาดโดย `src/arena-frost.js`) ยืนอยู่ตรงตำแหน่งปราสาทแล้ว
**เมื่อไฟล์ `snow-castle.glb` และรายการใน manifest เข้ามา เกมจะสลับไปใช้โมเดลจริงเองทันที** ไม่ต้องแก้โค้ดเกม

## 1. ปราสาทอยู่ตรงไหนในเกม และเกมใช้ไฟล์อย่างไร

- ที่ราบบนหน้าผาในเขต "วิหารน้ำแข็ง" (ทิศตะวันออกเฉียงเหนือ ถัดจากนครเก่า) ขึ้นจากหุบด้วยบันไดหินกว้างกลางหน้าผา
  ด้านหน้าปราสาทคือ "ลานบัลลังก์" วงกลมที่ราชินีหิมะยืนรอ (บอส) — ตำแหน่งทั้งหมดอยู่ใน `src/a.js` (`WD.fort`, ค่าคงที่ `FORT_*`)
- เกมวางโมเดลที่จุดกลางปราสาท (`FORT_VC`) หันประตูไปทางหุบ/บันได แล้ว **ย่อ-ขยายให้พอดีกรอบพื้น 900 × 560 หน่วยเกม** (คงสัดส่วน: `k = min(900/กว้าง, 560/ลึก)`)
  แล้วจมฐานลงพื้น 20 หน่วย (`arena-frost.js` → `place(... 'snow-castle' ...)`)
- **ชนทั้งผืน**: world gen ทำ collision เป็นวงกลมเรียงเต็มกรอบ 900 × 560 + หอมุมทั้งสี่ — ฮีโร่เดินเข้าข้างในปราสาทไม่ได้ (ไม่ต้องทำภายใน)
- กล้องเกมมองจากด้านหน้า-บน (มุมเงย 57°, หันไปทางทิศเหนือ = เห็น "หน้าประตู" และ **หลังคา/ยอดหอ** ชัดที่สุด) — ยอดหอ หลังคา หิมะบนหลังคา ต้องสวยเมื่อมองจากบน
- เขตวิหารน้ำแข็งมี shader ใส่หิมะบนผิวที่หงายขึ้นของทุกวัตถุให้อัตโนมัติ, มีกลางวัน/กลางคืน, หมอก, หมอกสงคราม (ที่มืดนอกระยะมองเห็น)
  และตอนฮีโร่เดินอ้อมไปหลังปราสาท ส่วนที่บังจะโปร่งแบบ dither ให้เห็นตัวละคร

## 2. หน่วยและทิศใน Blender (สำคัญ — ผิดทิศ ปราสาทจะหันหลังให้บันได)

- **1 เมตรใน Blender = 100 หน่วยเกม** → กรอบพื้น **9.0 m (แกน X) × 5.6 m (แกน Y)**
- จุด origin = กลางกรอบพื้น ที่ระดับพื้น (Z = 0); ฐานล่างสุดของโมเดลอยู่ที่ Z = 0 (เกมจะจมให้เอง 0.2 m)
- **ประตูหน้าหันไปทาง −Y ของ Blender** (ด้านที่มองเห็นในมุม Front / numpad 1) → ตอน export glTF (+Y up) จะกลายเป็น **+Z = หน้า** ตามที่เกมต้องการ
- ทุกชิ้นต้องอยู่ในกรอบ X ±4.5 m, Y ±2.8 m (ชิ้นที่ยื่นเกินกรอบจะทำให้ bounding box ใหญ่ขึ้น แล้วเกมจะย่อปราสาททั้งหลังลง) — ความสูงไม่จำกัดแต่แนะนำยอดสูงสุด 7–8 m

```
            ด้านหลัง (+Y ใน Blender)            
   ┌──O───────────────────────────────O──┐   O = หอมุม (กลางหออยู่ที่มุมกรอบพอดี, รัศมี ~0.75–0.9 m)
   │                                     │
   │        ┌───────── keep ─────────┐   │   keep = ตัวปราสาทหลัก + ยอดผลึกน้ำแข็งกลาง (สูงสุด)
   │        │   (หอหน้าซ้าย-ขวา)     │   │
   │        └────────────────────────┘   │
   │                                     │
   └──O──────────[ gatehouse ]────────O──┘
            ด้านหน้า = ประตู (−Y ใน Blender)  → หันไปทางบันได/ลานบัลลังก์
   กว้าง 9.0 m (X) × ลึก 5.6 m (Y)
```

## 3. ดีไซน์ (ปราสาทหิมะน้ำแข็งของราชินีหิมะ)

- โทน: หินสีฟ้าซีด-ขาวเทาเย็น ๆ, หลังคา/ยอดหอเป็นผลึกน้ำแข็งสีฟ้าใส (ทรงหกเหลี่ยมแหลม), หิมะหนาบนหลังคาและเชิงเทิน, ประตูและหน้าต่างเรืองแสงฟ้าอมเขียว (#7fe4ff)
  ให้เข้ากับตัวราชินี (`assets/meshy/ice-queen.glb`: เกราะผลึกน้ำแข็งฟ้า-ขาว มงกุฎผลึก) และคทา Frostwing Scepter (ผลึกปีกน้ำแข็ง)
- องค์ประกอบ (เรียงตามความสำคัญ):
  1. ฐาน/ลานหินยกพื้นทั้งกรอบ + ขั้นบันไดสั้นหน้าประตู
  2. กำแพงรอบสี่ด้าน สูง ~2.0–2.4 m มีเชิงเทิน (merlon) และหิมะบนสัน
  3. หอมุม 4 หอ (ทรงกลม/หกเหลี่ยม สูง ~3.5–4 m) หลังคากรวยผลึกน้ำแข็ง + ขอบหิมะ
  4. gatehouse หน้ากลาง: หอสี่เหลี่ยมคู่ + ซุ้มประตูโค้ง + บานประตูเรืองแสง/หรือม่านน้ำแข็งเรืองแสง
  5. keep กลางค่อนไปด้านหลัง: ตัวอาคารสูง + หอหน้าคู่ + **ยอดผลึกน้ำแข็งกลาง** (จุดเด่นที่สุด สูง ~7–8 m)
  6. รายละเอียด: ผลึกน้ำแข็งงอกจากกำแพง/มุม, ย้อยน้ำแข็ง (icicles) ใต้ชายคา/เชิงเทิน, หน้าต่างแคบเรืองแสง, ธง/ตราผลึก (ไม่บังคับ)
- ภาพรวมจากมุมกล้องเกม: silhouette ยอดแหลมหลายระดับ อ่านง่ายจากด้านบน, ไม่ทึบเป็นก้อนเดียว
- ไม่ต้องมีภายใน (ไม่มีห้อง/โถง) — ถ้าทำลานในกำแพง ให้ปิดด้วยหิมะ/ผลึก (ฮีโร่เข้าไปไม่ได้อยู่ดี)

## 4. ข้อจำกัดทางเทคนิค

- สามเหลี่ยมรวม **≤ 30,000**; ไฟล์ **≤ 1.5 MB** (AGENTS.md ข้อ 7: ห้าม commit GLB ใหญ่)
- วัสดุ PBR (metallic-roughness) **ไม่เกิน 5 ชนิด** เช่น
  - `Stone_Ice` หินฟ้าซีด: texture ต่อกันได้ (tileable) ≤ 1024² JPEG, roughness ~0.85
  - `Ice_Crystal` ผลึก: ไม่ต้องมี texture, base #bfe4ff, roughness ~0.1, metallic 0, emissive #2c6a9e strength ~0.4 — **ทึบ (Opaque) ห้ามใช้ Alpha Blend**
  - `Snow` ขาว #f4f8ff, roughness ~0.95
  - `Glow` ประตู/หน้าต่าง: emissive #7fe4ff strength ~1.5
  - (ไม่บังคับ) `Trim` โลหะเงินเข้ม roughness ~0.4 metallic ~0.8
- shader node ของ Blender ที่ export ไม่ได้ (noise/procedural) ต้อง bake เป็นภาพก่อน หรือใช้ค่าคงที่แทน
- normal ถูกทิศ, apply transform (scale = 1) และ apply modifier ทั้งหมดก่อน export, ไม่มีกล้อง/ไฟ/animation ในไฟล์
- export: **glTF Binary (.glb)**, +Y Up, เปิด Apply Modifiers, รูปแบบภาพ JPEG, **ไม่ใช้ Draco และไม่ใช้ meshopt/KTX2** (loader ของเกมไม่มีตัวถอด)

## 5. ขั้นตอนทำงาน (Codex)

1. branch `codex/snow-castle` จาก `main` (อ่าน `AGENTS.md`, `HANDOFF.md` ก่อน)
2. สร้างปราสาทด้วยสคริปต์ Python ของ Blender เพื่อให้สร้างซ้ำ/ปรับได้: `moonfall-docs/blender/snow_castle.py`
   รันแบบ headless: `blender -b -P moonfall-docs/blender/snow_castle.py -- app/src/main/assets/assets/meshy/snow-castle.glb`
   (ไฟล์ .blend และภาพ preview ไม่ต้อง commit)
3. render preview จากมุมกล้องเกม (กล้องอยู่หน้า-บน เงย 57° มองลงมาที่ปราสาท, ประตูหันเข้ากล้อง) เช็กว่ายอดหอ/หลังคา/ประตูอ่านง่าย
4. ตรวจไฟล์: ขนาด ≤ 1.5 MB, สามเหลี่ยม ≤ 30k, bounding box ≈ 9.0 × 5.6 m (อัตรากว้าง:ลึก ≈ 1.6), ประตูอยู่ฝั่ง +Z ของ glTF
5. เพิ่มรายการใน `app/src/main/assets/assets/meshy/manifest.json` **ภายใต้ `"assets"`** (ไม่ใช่ใต้ `"warrior"` ท้ายไฟล์):
   ```json
   "snow-castle": {
    "name": "Snow Castle (Codex, Blender) - the Snow Queen's ice castle on the Frozen Sanctuary's plateau",
    "url": "assets/meshy/snow-castle.glb",
    "available": true,
    "rotationY": 0,
    "biome": "arena",
    "rigged": false,
    "animations": [],
    "source": "Blender script moonfall-docs/blender/snow_castle.py (9.0 x 5.6 m footprint, gate +Z)"
   }
   ```
   `src/build.py` ใส่ `snow-castle` เข้า `CELESTIAL_KEYS` ของ index เองเมื่อมีใน manifest (`FORT_NEW`) — ไม่ต้องแก้ build.py
6. build: `cd src && python3 build.py` แล้วก๊อป `index.html` ไป `app/src/main/assets/` (ไม่ต้อง build/ทดสอบ `cursed.html` — เจ้าของสั่งเลิกดูแลแล้ว 2026-11-23)
7. ทดสอบผ่าน http server (ไม่ใช่ file://): เข้าเกม index → ใน console `R3.fortModel` ต้องเป็น `'snow-castle'` (ถ้าเป็น `'palace'` = ยังใช้ปราสาทชั่วคราว)
   เดินไปที่ไอคอน ❄️ บนมินิแมพ: ปราสาทต้องตั้งบนที่ราบพอดี ไม่ลอย/ไม่จม ประตูหันไปทางบันได, ฮีโร่ชนขอบปราสาทพอดีกับตัวโมเดล, ไม่มี error ใน console
8. เขียน `HANDOFF.md` + บรรทัดใน README "มีอะไรใหม่" แล้วเปิด PR เข้า `main`
