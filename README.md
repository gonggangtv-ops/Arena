# Arena Royale v0.5.1 — หุบเขาแห่งเทพนิยาย (MOBA แบทเทิ้ลรอยัล)

**เล่นบนเว็บ:** https://gonggangtv-ops.github.io/Arena/

ตัวเกมอยู่ที่ `app/src/main/assets/index.html` (HTML5 + Three.js) แอป Android เป็น WebView ห่อเกม ส่วนเว็บใช้ไฟล์ชุดเดียวกัน

## มีอะไรใหม่
- **⚡ จับคู่ด่วน (v0.5.1)** กดปุ่มเดียวสุ่มเจอผู้เล่นออนไลน์ที่กำลังหาเกมอยู่ (เว็บกับแอป APK เจอกันได้) รอสูงสุด 30 วินาที ที่ว่างเติมด้วยบอทให้ครบ 16 คน
- **เล่นออนไลน์บนเว็บได้** ผ่าน GitHub Pages (ส่งลิงก์ให้เพื่อนเปิดในเบราว์เซอร์ได้เลย) และเล่นข้ามกับแอป APK ได้
- **ธีมหุบเขาแห่งเทพนิยาย** หุบเขากลมล้อมด้วยภูเขาหิมะ น้ำตกไหลลงแม่น้ำคดเคี้ยวไปทะเลสาบ หมู่บ้าน 6 แห่ง (เมืองน้ำพุ ฟาร์มกังหันลม ริมทะเลสาบ หมู่บ้านแม่มด ค่ายคนตัดไม้ ปลายหุบ) ปราสาทมังกร สะพานหินโค้ง ถ้ำลับในภูเขา (มีถ้ำหลังน้ำตก)
- **แมพใหญ่ขึ้น** โลก 10000×10000 พื้นที่เล่นราว 1.4 เท่าของเดิม ผู้เล่นรวม 16 คน (คนจริงสูงสุด 8)
- **กลางวันมองเห็นใกล้ลง** (860 จากเดิม 1150) กลางคืน 620
- **กราฟิกสมจริงขึ้น** พื้นผิวแบบ texture ทั้งหญ้า ดิน หิน ถนนหิน หิมะ น้ำมีความลึก ต้นไม้ไหวตามลม บ้านโครงไม้หลังคากระเบื้อง/ฟาง แสงเช้า-เย็น-กลางคืน เงาเมฆ หน้าต่างเรืองแสงตอนกลางคืน
- **ไม่มีอาชีพแล้ว** เริ่มมือเปล่า เก็บอาวุธอะไรได้สกิลชุดนั้น (ระดับสกิลติดตัว เปลี่ยนอาวุธได้)
- **เกราะ 5 ระดับ** เห็นบนตัวละคร: ผ้า → หนัง → โซ่ → เหล็ก → เกราะมังกร
- **เอฟเฟกต์สกิลใหม่** อนุภาคไฟ น้ำแข็ง ควัน วงเวทรูน คลื่นกระแทก รอยไหม้ แสงลากดาบ
- บอสใหม่: **มังกรเพลิง** ในปราสาท พ่นไฟเป็นรูปกรวยและกระแทกปีก ปราบแล้วได้โล่อมตะ อาวุธตำนาน และเกราะมังกร

## อาวุธ 6 ชุด (Q / W / R)
| อาวุธ | จุดเด่น | Q | W | R (อัลติ) |
|---|---|---|---|---|
| 🗡️ ดาบและโล่ | ทน เกราะ+3 | พุ่งชนสตัน | โล่ดูดซับดาเมจ | กระโดดฟาดพื้น สตันวงกว้าง |
| 🪓 ขวานยักษ์ | ฟันกวาด ดูดเลือด | หมุนขวานเป็นพายุ | คำรามศึก (ศัตรูช้า เราตีไว วิ่งเร็ว) | ผ่าปฐพีเป็นแนวยาว |
| 🔪 มีดคู่ | ตีไว คริแรง | วาร์ปไปหลังศัตรู | ล่องหน (ตีแรกแทงหลัง) | ระบำมรณะรอบตัว |
| 🏹 ธนูยาว | ยิงไกล | ยิงกระจาย 5 ดอก | ถอยหลังพร้อมยิงศรตรึง | ฝนธนู |
| 🔥 คทาเพลิง | เวทไฟ | ลูกไฟระเบิด | ระเบิดเพลิงผลักศัตรู + ติดไฟ | อุกกาบาต |
| ❄️ คทาน้ำแข็ง | ควบคุม | หอกน้ำแข็งทะลุ | วงน้ำแข็งตรึง | พายุหิมะ (จบแล้วแช่แข็ง) |

อาวุธมี 4 ระดับ (ธรรมดา/หายาก/มหากาพย์/ตำนาน) ระดับสูงแรงขึ้นและสกิลแรงขึ้น · เดินชนอาวุธชนิดเดียวกันที่ดีกว่าจะเก็บอัตโนมัติ ถ้าเป็นอาวุธต่างชนิดจะมีปุ่ม **🔄 เปลี่ยนเป็น…** (คีย์บอร์ดกด F)

## เล่นออนไลน์บนเว็บ (GitHub Pages)
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น branch `main` (รวมโฟลเดอร์ `.github`)
2. workflow "Deploy web game (GitHub Pages)" จะคัดลอกเกมไปไว้ที่ branch `gh-pages` ให้เองทุกครั้ง (รอ 1–2 นาที)
3. เกมจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` · ถ้าเป็น repo ใหม่แล้วหน้าเว็บยังไม่ขึ้น ไปที่ **Settings → Pages → Source** เลือก **Deploy from a branch** → `gh-pages` / `(root)`
4. กด **⚡ จับคู่ด่วน** เพื่อสุ่มเจอผู้เล่น หรือ **สร้างห้องกับเพื่อน** แล้วกด **คัดลอกลิงก์** ส่งให้เพื่อน

เว็บกับแอป APK เวอร์ชันเดียวกันเข้าห้องเดียวกันได้ (คนละเวอร์ชันจะหาห้องกันไม่เจอ)

**ถ้าเชื่อมต่อไม่ติด:** ส่วนใหญ่เกิดกับเน็ตมือถือบางค่าย ให้ต่อ Wi-Fi เดียวกัน หรือสมัคร TURN ฟรีของ Metered (20 GB/เดือน) แล้วใส่ค่า `iceServers` ในไฟล์ `app/src/main/assets/turn.js` ตามตัวอย่างในไฟล์ (ค่านี้จะเห็นได้จากหน้าเว็บ ใครก็ใช้โควตาได้)

## ⚡ จับคู่ด่วน (สุ่มเจอผู้เล่น)
- กด **⚡ จับคู่ด่วน** เกมจะค้นหาห้องที่มีคนรออยู่ราว 4 วินาที ถ้าเจอจะเข้าห้องที่คนเยอะที่สุด ถ้าไม่เจอจะเปิดห้องรอให้คนอื่นมาเจอ
- ในห้องมีนับถอยหลัง 30 วินาที หมดเวลาแล้วเริ่มทันที (มีคนเข้ามาใหม่จะต่อเวลาให้อย่างน้อย 10 วินาที) คนเปิดห้องกด **เริ่มเลย** ก่อนหมดเวลาได้
- จบเกมกด **⚡ จับคู่ใหม่** เพื่อหาห้องใหม่ทันที
- ถ้าห้องที่รออยู่ปิดไปหรือเต็ม เกมจะหาห้องใหม่ให้เอง
- เครื่องที่เปิดห้องเป็นโฮสต์ ถ้าโฮสต์ปิดแอประหว่างเกม เกมของทุกคนในห้องจะจบ (โฮสต์ที่ตายแล้วต้องรอเกมจบก่อนจึงออกได้ ยกเว้นเล่นอยู่คนเดียวกับบอท)
- ทุกคนต้องใช้เวอร์ชัน 0.5.1 ขึ้นไปจึงจะเจอกันในจับคู่ด่วน (ห้องแบบใส่รหัสยังเล่นกับ 0.5 ได้)

## สร้าง APK ด้วย GitHub (ไม่ต้องลงโปรแกรม)
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวม `.github`) เข้า branch `main`
2. แท็บ **Actions** รอ "Build APK" ขึ้นเครื่องหมายถูกสีเขียว (3–5 นาที) · ถ้าอัปโหลดผ่านหน้าเว็บ GitHub ให้เลือก branch `main` ก่อน (ไม่ใช่ `gh-pages`)
3. **Releases → Arena Royale (ล่าสุด)** ดาวน์โหลด `ArenaRoyale.apk` บนมือถือแล้วติดตั้ง

## สร้างด้วย Android Studio
เปิดโฟลเดอร์นี้ใน Android Studio → Build → Build APK(s)
